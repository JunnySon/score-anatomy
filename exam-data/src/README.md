# 원본 시험 파일

발행할 시험 파일의 원본을 두는 곳이에요(작업 지시서 3의 6-1). 사람이 고치고, 발행 도구(`npm run exams:check` 등)는 이 폴더의 `*.json` 만 읽어요. 이 파일(README.md)은 빈 폴더를 git 에 남기려고 둔 자리 파일이에요.

- 파일 이름은 시험 id 에 `.json` 을 붙여요(형식 예시: `test-only-exam.json`). id 는 영어 소문자와 숫자를 붙임표(-)로 이어서 써요.
- 파일 안에 `rev` 를 꼭 적어요(처음은 1). 발행한 시험을 고쳐 낼 때마다 1씩 올려요.
- 시험 파일의 칸은 docs/시험_추가_방법.md 1장과 같아요. 검사 규칙은 src/exams/validate.ts 하나예요.
- 실제 시험의 정답, 배점, 등급컷, 시행일은 주관 기관의 공고와 자료를 확인한 사람만 넣어요.
