# iOS 화면 비교

결론: 작업 지시서 3-2에서 웹 묶음 0.3.1(manifest 커밋 da5217a)을 실은 iOS 캡처를 웹 캡처(같은 0.3.1), 지난 iOS 캡처(웹 묶음 0.2.0), Release 캡처와 나란히 놓고 모두 봤어요. 웹과 다른 곳은 지난번과 같은 알려진 차이(안전 영역, 앱의 시스템 글꼴, 앱 안 문구, 화면 폭에 따른 줄바꿈, 캡처 위치)뿐이에요. 지난 캡처와 달라진 곳은 웹이 고친 네 가지(키패드 판이 아래 끝까지, 예시 시험 C 설명 줄바꿈, 진행 막대 왼쪽 끝의 틈, 표시 화면 아래 단서)와 시스템이 그리는 홈 표시 막대예요. Release 와 Debug 는 기록 화면의 준비 중인 기능 목록과 "테스트 진행자용" 링크 말고 같아요. 껍데기 문제는 없었고, 캡처 하나(측정카드)는 카드가 화면에 들어오지 않게 찍혀 값을 캡처로는 볼 수 없어요(아래). 웹 파일은 고치지 않았어요.

## 비교한 방법

- iOS 캡처: 마지막 verify(2026-11-24 21:54~22:58, 커밋 96144a8)가 찍었어요. CaptureTests 의 36장(9화면 x 밝은, 어두운 화면 x iPhone 17, iPhone SE 3세대), 참고 캡처(docs/screens-ios/extra), Release 와 Debug 의 같은 화면 18장(docs/screens-ios/release), 확대 캡처 8장(docs/screens-ios/zoom, ios/scripts/zoom_crop.swift 로 화소를 그대로 키움).
- 웹 캡처: docs/screens/light, dark(390 x 844, 2배)와 small(360 x 640, 1배, 밝은 화면만). 웹 묶음 0.3.1 로 찍은 것이에요(main 1bcc9b4).
- 지난 iOS 캡처: 작업 지시서 2의 마지막 캡처(웹 묶음 0.2.0, 커밋 8c61bf9 의 docs/screens-ios).
- 짝: 01-시작과 01-시작, 02-시험선택과 04-시험선택, 03-답입력-키패드와 08-답입력-키패드-객관식, 04-잠금과 10-답입력-키패드-잠금, 05-입력확인과 17-입력확인, 06-표시와 22-표시-붙임(맨 위 상태는 21-표시-처음), 07-점수해부와 27-점수해부-2등급, 08-계단과 32-계단, 09-기록과 43-기록.
- 구현에 참여하지 않은 에이전트 6명이 iPhone 17 밝은 화면(둘로 나눔), 어두운 화면, SE, Release 와 Debug, 참고 캡처와 확대 캡처를 나눠 열어 보고 화소 값까지 견줬어요. 아래 표는 그 결과를 제가 다시 확인해 합친 것이에요.
- 이번 캡처에는 화면 아래 가운데에 iOS 의 홈 표시 막대(iPhone 17 의 861~866pt)가 찍혀요. 지난 캡처에는 없었어요. 같은 기기와 OS 이고 캡처 코드와 껍데기 코드에 홈 표시를 다루는 바뀜이 없어서, 까닭은 확인하지 못했어요(시뮬레이터의 스크린샷 환경 차이로 추측). 안전 영역 안이라 내용과 겹치지 않아요.

## Release 와 Debug(작업 지시서 3-3)

같은 화면 테스트(LookTests)를 Debug 와 Release 로 돌려, 상태를 심는 장치 없이 같은 누름으로 같은 화면까지 가서 찍었어요(docs/screens-ios/release/debug, release). 자동 비교(verify 15번)는 화면 전체 화소(채널 차이 8 넘는 화소), 요소의 있고 없음, 자리, 크기, 요소마다 잘라 견준 화소를 봐요(docs/ios_결정기록.md 4장).

| 화면 | 달라야 하는 곳 | 실제로 다른 곳 | 화면 전체 화소 차이(채널 8 넘음) | 판단 |
| --- | --- | --- | --- | --- |
| 01 시작 | 없음 | 없음. 눈으로 같고 요소 25개의 자리와 크기가 같음. 빗금 칸 안에 채널 값 1 차이 화소 217개가 있음(보이지 않음) | 0 | 같음 |
| 02 시험 선택 | 없음 | 없음(파일이 SHA-256 까지 같음) | 0 | 같음 |
| 03 답 입력 | 없음(입력 방식 전환은 일반 화면에 없음, 진행자용 화면의 칩과 주소 값에만 있음) | 없음(SHA-256 같음) | 0 | 같음 |
| 04 입력 확인 | 없음 | 없음(SHA-256 같음) | 0 | 같음 |
| 05 표시 | 없음 | 없음(SHA-256 같음, 찍음 빗금 칸 5개 포함) | 0 | 같음 |
| 06 점수 해부 | 없음 | 없음(SHA-256 같음) | 0 | 같음 |
| 07 계단 | 없음 | 없음(SHA-256 같음) | 0 | 같음 |
| 08 기록(맨 위) | 준비 중인 기능 목록, "테스트 진행자용" 링크 | Debug 에만 목록(y 314~539pt)과 링크(y 578pt)가 있고, 그래서 "앱을 지우면 기록도 함께 지워져요." 줄의 자리가 다름(Debug 635pt, Release 306pt) | 0(위에서 302pt 까지 견줌) | 달라야 하는 곳만 다름. Release 의 300pt 아래 내용은 Debug 를 329pt 위로 옮겨 견주면 화소까지 같아요 |
