# 자료 이용 근거

결론: 다른 기관이 낸 시험 자료(정답, 등급컷 추정치, 시험 시간표 등)를 앱과 발행물에 쓸 때, 그 근거를 기관마다 적는 빈 양식이에요. 내용은 기관에 문의하고 답을 받은 사람이 채워요. 이 저장소를 만드는 동안에는 어느 기관에도 문의하지 않았고 바깥 사이트에서 자료를 가져오지 않아서, 아래 기록은 비어 있어요.

## 칸

| 칸 | 적는 것 |
| --- | --- |
| 기관 | 자료를 낸 기관의 이름. 등급컷 추정치면 exams:cuts 입력 파일의 source 와 같은 이름으로 적어요 |
| 문의한 날 | 문의한 날짜(YYYY-MM-DD) |
| 답변을 받은 방식과 보관한 곳 | 답변을 받은 방식(전자우편, 공문 등)과 그 답변을 보관한 곳 |
| 허용받은 범위 | 쓸 수 있는 자료, 쓰는 곳(앱 화면, 발행물), 기간 |
| 조건 | 출처를 적는 방식, 그 밖에 지켜야 할 것 |
| 다시 확인할 것 | 다시 물어볼 때와 내용(기간이 끝나는 날, 조건이 바뀌었는지 등) |

담당자의 개인 연락처는 이 파일에 적지 않아요(저장소에 남아요).

## 기록

| 기관 | 문의한 날 | 답변을 받은 방식과 보관한 곳 | 허용받은 범위 | 조건 | 다시 확인할 것 |
