# 2027학년도 수능 수학(확률과 통계) 입력지

[1번 입력지](suneung-2027-math-probstat.1.csv)와 [2번 입력지](suneung-2027-math-probstat.2.csv)에 한국교육과정평가원의 **공식 정답표와 시험지**를 보고 입력해요. 각 장에 공통 22문항과 확률과 통계 8문항을 모두 적어요.

1. 시험지와 정답표의 학년도, 과목, 문형(홀수형 또는 짝수형)을 맞춰요. 두 장에 같은 문형을 사용해요. 1~22번은 공통, 23~30번은 확률과 통계 쪽에서 찾아요.
2. 1번 장에 문항별 배점, 정답, 유형을 적어요. 미리 넣은 번호, 객관식과 단답형의 구분, 보기 수도 시험지와 견줘요. 틀린 부분이 보이면 문항 번호와 함께 알려 주세요.
3. 시간을 두고 1번 장을 닫은 상태에서 공식 자료를 다시 보며 2번 장을 처음부터 채워요. 한 장을 복사하면 잘못 옮긴 값까지 두 장에 똑같이 남아요.
4. 두 파일을 원래 이름으로 **CSV UTF-8(쉼표로 분리)** 형식으로 저장해요. 두 장을 채운 뒤 **“입력 끝”**이라고 해 주세요. 사용한 문형, 각 장을 입력한 사람과 시각을 함께 알려 주면 진행기록에 남겨요.

## 문항마다 적는 칸

| 칸 | 넣을 값 |
| --- | --- |
| `no` | 1부터 30까지 차례대로예요. 한 줄이 한 문항이에요. |
| `kind` | 1~15번과 23~28번은 `mc`(객관식), 16~22번과 29~30번은 `short`(단답형)예요. |
| `choices` | 객관식은 `5`이고 단답형은 비워요. |
| `points` | 시험지에 적힌 배점을 양의 정수로 적어요. 30문항의 합계는 100점이에요. |
| `answer` | 정답표의 값을 숫자로 적어요. 객관식은 1~5, 단답형은 0~999예요. 단답형 정답이 0이면 숫자 `0`을 적어요. |
| `typeId` | 아래 목록에서 고른 유형 번호예요. 유형이 애매해도 가장 가까운 번호를 적어요. |
| `memo` | 유형이 애매하면 `확실하지 않음`이라고 적어요. 보통은 비워요. 메모도 두 장을 견주며, 시험 JSON에는 싣지 않아요. |

정답, 배점, 유형은 필수예요. 열 이름과 순서를 유지하고 숫자에는 단위나 수식을 붙이지 않아요. 공식 정답표에 한 문항의 정답이 여러 개이거나 모두 정답이라는 표시가 있다면, 값 하나를 임의로 골라 적지 말고 그 문항을 알려 주세요.

## 유형 번호

저장소의 `src/exams/sample-a.json`에 있는 유형 이름이에요. 문항의 유형은 공식 시험지의 내용을 보고 골라요.

| 번호 | 뜻 |
| --- | --- |
| `t01` | 지수와 로그 |
| `t02` | 삼각함수 |
| `t03` | 수열 |
| `t04` | 함수의 극한과 연속 |
| `t05` | 미분 |
| `t06` | 적분 |
| `t07` | 경우의 수 |
| `t08` | 확률 |
| `t09` | 통계 |
| `t10` | 지수함수와 로그함수 |

## 입력을 마친 뒤

저장소 루트에서 `node scripts/exams.mjs entry`를 실행해요. 사용한 문형을 알면 `node scripts/exams.mjs entry 홀수형` 또는 `node scripts/exams.mjs entry 짝수형`으로 실행해요. 이때 시험 선택 화면의 설명에 해당 문형이 표시돼요.

두 장의 모든 칸을 견줘 문항 번호와 다른 칸을 알려 줘요. 차이가 있으면 두 장 모두 공식 자료로 돌아가 해당 칸을 확인해요. 필수 칸, 문항 형식, 배점 합계, 시험 규격을 모두 통과하면 `exam-data/src/suneung-2027-math-probstat.json`을 만들어요. 메모에 `확실하지 않음`이 있는 문항 번호도 알려 줘요. 처음 만드는 원본은 1판이고 시행일은 2026-11-19예요. 지난 시험과 정답 공개 상태로 만들고 등급컷은 생략해요.
