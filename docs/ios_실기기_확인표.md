# 실기기 확인표

결론: 시뮬레이터 검증(docs/ios_검증결과.md)은 실제 아이폰의 손 박자, 햅틱 느낌, VoiceOver 사용, 전원을 껐다 켠 뒤의 기록을 대신하지 못해요. 앞부분(1장)을 따라 내 아이폰에 앱을 올리고, 뒷부분(2장)의 표를 사람이 직접 채워 주세요. Xcode 를 처음 쓰는 사람 기준으로 적었어요.

## 1. 아이폰에 올리는 방법

### 1-1. 준비물

- Mac 과 Xcode 26 이상(Mac App Store 에서 설치).
- iOS 17 이상의 아이폰과 Mac 에 꽂을 케이블.
- Apple 계정(아이폰에 쓰는 계정이면 돼요). 무료 계정으로도 내 아이폰에 올려 볼 수 있어요(1-8 의 제한이 있어요).

### 1-2. 프로젝트 열기

1. Finder 에서 저장소의 `ios` 폴더를 열고 `ScoreAnatomy.xcodeproj` 를 두 번 눌러요.
2. 처음 열면 Xcode 가 프로젝트를 읽느라 몇십 초 걸려요. 창 위쪽에 진행 막대가 사라질 때까지 기다려요.

### 1-3. Apple 계정 추가

1. 메뉴 막대에서 Xcode, Settings 를 눌러요(Command + 쉼표).
2. Accounts 탭에서 왼쪽 아래 + 를 누르고 Apple Account 를 골라 로그인해요.
3. 목록에 계정이 생기고 오른쪽에 팀이 보이면 돼요. 무료 계정이면 "(Personal Team)" 이라고 나와요.

### 1-4. Team 고르기

1. 왼쪽 파일 목록 맨 위의 파란 아이콘 ScoreAnatomy 를 눌러요.
2. 가운데 화면의 TARGETS 에서 ScoreAnatomy 를 고르고 위쪽 탭에서 Signing & Capabilities 를 눌러요.
3. Automatically manage signing 이 켜져 있는지 보고, Team 에서 1-3 에서 추가한 팀을 골라요.
4. 빨간 오류가 남으면 1-5 의 번들 ID 를 바꾼 뒤 다시 봐요.

참고: 나중에 `xcodegen generate` 로 프로젝트 파일을 다시 만들 사람은 이 화면 대신 `ios/Config/Signing.local.xcconfig` 에 적어 두면 지워지지 않아요(ios/README.md 4장).

### 1-5. 번들 ID 바꾸기

- 지금 번들 ID `com.junnyson.scoreanatomy` 는 임시 값이에요. 다른 계정이 이미 쓰고 있으면 등록되지 않아요.
- 같은 화면(Signing & Capabilities)의 Bundle Identifier 칸을 `com.내영문이름.scoreanatomy` 처럼 나만 쓰는 값으로 바꿔요. 영문, 숫자, 점, 하이픈만 써요.
- 앱 안의 기록 폴더 이름도 번들 ID 를 따라가요. 번들 ID 를 바꾸면 다른 앱으로 보고 기록이 따로 쌓여요.

### 1-6. 아이폰 연결과 개발자 모드

1. 케이블로 아이폰을 Mac 에 꽂고 아이폰의 잠금을 풀어요.
2. 아이폰에 "이 컴퓨터를 신뢰하겠습니까?"가 뜨면 신뢰를 누르고 암호를 넣어요.
3. Xcode 창 위쪽 가운데의 실행 대상 목록에서 내 아이폰을 골라요.
4. 아이폰의 설정, 개인정보 보호 및 보안, 맨 아래 개발자 모드를 켜요. 아이폰이 다시 시작되고, 다시 켜지면 개발자 모드를 켤지 한 번 더 묻는데 켜기를 눌러요. 개발자 모드 메뉴는 Xcode 에 한 번 연결한 뒤에 보여요.
5. 처음 연결하면 Xcode 가 기기를 준비하느라 몇 분 걸릴 수 있어요(상태 표시가 끝날 때까지 기다려요).

### 1-7. 처음 켤 때 기기에서 눌러야 하는 것

1. Xcode 에서 실행 버튼(삼각형)이나 Command + R 을 눌러요.
2. 무료 계정이면 아이폰에 "신뢰하지 않는 개발자" 안내가 뜨고 앱이 켜지지 않아요.
3. 아이폰의 설정, 일반, VPN 및 기기 관리에서 개발자 앱 아래 내 Apple 계정을 누르고, 신뢰를 눌러요.
4. 다시 Xcode 에서 실행하거나 홈 화면의 "점수 해부"를 눌러요.

### 1-8. 무료 계정으로 올린 앱의 제한

- 무료 계정으로 올린 앱은 며칠(Apple 이 정한 기간, 보통 7일) 뒤 켜지지 않아요. 그때 Xcode 에서 다시 실행하면 새로 서명돼요. 기록 파일은 앱을 지우지 않는 한 남아요.
- 무료 계정은 TestFlight 와 App Store 에 올릴 수 없어요. 고등학생 사용성 테스트를 여러 기기로 하려면 유료 개발자 프로그램과 TestFlight 가 필요해요(docs/ios_출시_준비.md).
- 무료 계정은 한 번에 올려 둘 수 있는 앱과 기기 수에도 제한이 있어요. 자세한 조건은 docs/ios_출시_준비.md 의 개발자 계정 조건에 확인한 날짜와 함께 적었어요.

### 1-9. 시험용 묶음과 배포용 묶음

- Xcode 에서 그냥 실행하면 Debug 빌드라 시험용 묶음이 실려요(기록 화면 아래 "테스트 진행자용" 링크가 있어요).
- 배포용 묶음으로 보려면 메뉴의 Product, Scheme, Edit Scheme 에서 Run 의 Build Configuration 을 Release 로 바꾸고 실행해요. 확인이 끝나면 Debug 로 되돌려요.
- 앱을 지우면 기록도 함께 지워져요.
