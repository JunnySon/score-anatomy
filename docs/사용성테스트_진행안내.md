# 사용성 테스트 진행 안내

결론: 고2 8~10명에게 종이 답지를 주고 이 앱으로 답 30개를 넣게 해서, 답 입력 시간, 남은 오입력, 결과 화면을 바르게 읽는지를 재요. 입력 방식 2종(키패드, 5행)은 같은 참가자가 순서를 바꿔 둘 다 써요. 측정은 앱이 이 기기 안에 자동으로 남기고, 파일이나 복사로만 꺼내요.

아래 통과 기준은 제안값이에요. 8~10명으로는 통계 검증을 할 수 없어요. 방향을 확인하는 용도로만 써요.

## 1. 준비

- 폰: 참가자 본인 폰이 좋아요. 주소로 열 수 있게 정적 호스팅 주소나 같은 와이파이의 개발 서버 주소를 준비해요(README.md 의 "폰에서 여는 방법").
- 종이 답지 2장: 아래 "답지 A"와 "답지 B". 실제 시험지처럼 번호 옆에 답을 손으로 적어 두면 좋아요.
- 진행자용 기록지: 참가자 코드, 방식 순서, 관찰한 말과 행동, 읽기 질문의 답을 적어요.
- 동의: 참가자가 미성년자예요. 보호자와 본인에게 무엇을 재는지 알리고 동의를 받아요. 이름, 학교, 성적은 받지 않아요. 앱에는 참가자 코드(P01, P02 같은 형식)만 넣어요.
- 테스트는 실력 평가가 아니라는 점을 먼저 말해요. 예: "앱이 쓰기 편한지 보는 거예요. 틀려도 되고, 막히면 막혔다고 말해 주면 돼요."

### 답지 A (예시 시험 A, 키패드와 5행 가운데 첫 번째 방식에서 사용)

```
1번 3   2번 5   3번 2   4번 4   5번 1
6번 3   7번 5   8번 2   9번 4   10번 1
11번 4  12번 5  13번 3  14번 1  15번 1
16번 2  17번 4  18번 5  19번 1  20번 3
21번 5  22번 12 23번 7  24번 36 25번 150
26번 24 27번 146 28번 9 29번 275 30번 48
```

- 세모(찍음) 표시를 해 둘 문항: 9번, 11번, 14번, 20번, 21번
- 붙여 넣을 답지: `3,5,2,4,1,3,5,2,4,1,4,5,3,1,1,2,4,5,1,3,5,12,7,36,150,24,146,9,275,48`
- 이 답지는 앱의 "예시 결과 보기"와 같은 응답이에요. 채점하면 78점이 나와요.

### 답지 B (예시 시험 B, 두 번째 방식에서 사용)

```
1번 2   2번 4   3번 1   4번 5   5번 3
6번 2   7번 5   8번 1   9번 3   10번 5
11번 1  12번 안 풂  13번 2  14번 5  15번 3
16번 5  17번 19 18번 42 19번 120 20번 64
21번 안 풂  22번 315 23번 4  24번 2  25번 5
26번 1  27번 3  28번 2  29번 27 30번 97
```

- 세모(찍음) 표시를 해 둘 문항: 3번, 7번
- 붙여 넣을 답지: `2,4,1,5,3,2,5,1,3,5,1,x,2,5,3,5,19,42,120,64,x,315,4,2,5,1,3,2,27,97`
- 안 푼 문항(12번, 21번)이 들어 있어서 "안 풂"을 찾는지도 볼 수 있어요. 채점하면 82점이 나와요.

두 답지를 쓰는 까닭은 같은 답을 두 번 넣으면 두 번째가 외워서 빨라지기 때문이에요.

## 2. 입력 방식 2종을 순서를 바꿔 쓰게 하는 방법

같은 참가자가 두 방식을 모두 쓰고, 참가자마다 순서를 바꿔요. 먼저 쓴 방식이 유리하거나 불리해지는 것을 줄이려는 거예요.

| 참가자 | 첫 번째 | 두 번째 |
| --- | --- | --- |
| P01, P03, P05, P07, P09 | 키패드 방식 + 답지 A | 5행 방식 + 답지 B |
| P02, P04, P06, P08, P10 | 5행 방식 + 답지 A | 키패드 방식 + 답지 B |

- 답지는 늘 A가 먼저, B가 나중이에요. 방식만 엇갈려요. 이렇게 하면 방식 비교에 답지 차이가 섞여요(키패드 기록의 절반은 답지 A, 절반은 답지 B). 참가자가 10명이면 방식마다 A 5명, B 5명으로 균형이 맞아요.
- 사람 수가 홀수면 균형이 깨져요. 그때는 방식별 비교를 같은 답지끼리만 해요.
- 첫 번째 방식에서는 점수 해부 화면까지 끝까지 가요. 두 번째 방식은 입력 확인을 지나 점수 화면까지만 가도 돼요(답 입력 시간과 남은 오입력만 비교).

## 3. 진행 순서 (한 사람에 20~25분)

1. 진행자가 폰에서 주소 끝에 `#/test` 를 붙여 테스트 진행자용 화면을 열어요(기록 화면 맨 아래 "테스트 진행자용" 링크로도 들어가요).
2. 참가자 코드(예: P01), 입력 방식, 시험(예시 시험 A)을 고르고 "테스트 시작하기"를 눌러요. 시작 화면으로 돌아가요. 이때부터 측정 기록이 남아요.
3. 폰과 답지 A를 참가자에게 줘요. 과제는 이것 하나예요: "오늘 모의고사를 봤다고 생각하고, 이 답지의 답을 넣어서 점수를 확인해 보세요."
   시험지에 세모 친 문항은 풀이 없이 고른 문항이라고만 알려 줘요. 앱 사용법은 설명하지 않아요.
4. 참가자가 점수 화면에 닿을 때까지 지켜봐요. 도와준 일이 있으면 기록지에 적어요(180초 기준은 "도움 없이"예요).
5. 이어서 "틀린 문항 살펴보기"부터 점수 해부, 계단까지 스스로 가 보게 해요. 원인은 15번과 29번만 "풀 줄 아는데 틀렸어요", 나머지는 "풀이가 안 떠올랐어요"로 고르게 답지 뒷면에 적어 둬요.
6. 점수 해부 화면에서 목표 등급 2등급을 고르게 한 뒤, 화면을 보면서 읽기 질문 3개를 물어요(아래 4번).
7. 진행자가 폰을 받아 `#/test` 화면으로 가요. "정답지 대조" 칸에 답지 A의 붙여 넣을 답지를 넣고 "답지와 비교하기"를 눌러 남은 오입력 수를 확인해요.
8. "이 참가자 마치기"를 눌러요.
9. 같은 참가자 코드로 다른 입력 방식과 예시 시험 B를 골라 다시 시작하고, 답지 B로 2~4번과 7~8번을 되풀이해요.
10. 끝으로 두 방식 가운데 어느 쪽이 편했는지, 왜 그런지 물어요. 표시 화면에서 "표시하면 점수가 깎이는 줄 알았는지"도 물어요.
11. 기기 한 대를 여러 참가자가 돌려 써도 앞 참가자의 점수는 다음 참가자에게 보이지 않아요(1.1).
    - 측정이 진행 중일 때는 기록 탭에 이번 참가자의 기록만 보이고, "이 기기의 기록 모두 지우기"는 숨겨져요.
    - "이 참가자 마치기"를 누른 뒤 다음 참가자를 시작하기 전(대기)에는 기록 탭에 기록이 보이지 않고 "테스트 기기예요. 기록은 진행자용 화면에서 확인해요."만 나와요. 시작 화면에도 "이어서 보기"가 나오지 않아요.
    - 참가자의 시험 기록은 기기에 그대로 남아요(학생이 보는 화면에는 나오지 않아요). 진행자용 화면의 측정 카드, 답지 대조, 내보내기는 참가자를 마칠 때 측정 기록에 옮겨 둔 사본을 써서, 시험 기록을 지워도 바뀌지 않아요. 테스트가 모두 끝나고 진행자용 화면에서 "기록 초기화"로 측정 기록을 지우면 기록 탭이 평소대로 돌아가요. 그때 참가자들의 시험 기록이 다시 보이므로, 기기를 돌려주기 전에 기록 화면의 "이 기기의 기록 모두 지우기"도 눌러요.

참가자가 테스트 중간에 "예시 결과 보기"를 눌러도 괜찮아요. 화면 진입 기록에 demo/anatomy 로 남아요.

## 4. 읽기 질문 3개

점수 해부 화면(답지 A 결과, 목표 2등급)을 보면서 물어요. 답을 알려 주지 않아요.

| 질문 | 바른 답 |
| --- | --- |
| "실수라고 표시한 8점은 78점 안에 들어 있나요?" | 아니요 |
| "78점 가운데 찍었다고 표시한 문항에서 나온 점수는 몇 점인가요?" | 7점 |
| "약 75점은 무엇을 뜻하나요?" | 찍기 운을 평균으로 본 추정 |

참가자가 원인을 답지와 다르게 골랐으면 화면의 숫자가 달라져요. 그때는 시작 화면의 "예시 결과 보기"를 열고 2등급을 골라 그 화면으로 물어요. 예시 결과는 늘 78점, 7점, 8점, 약 75점이에요.

## 5. 앱이 자동으로 남기는 것

진행자가 "테스트 시작하기"를 누른 뒤부터 "이 참가자 마치기"를 누를 때까지, 이 기기 안에만 남아요.

| 측정 | 뜻 |
| --- | --- |
| 화면별 진입 시각 | 화면이 바뀔 때마다 화면 이름과 시각 |
| 답 입력 시간 | 답 입력 화면에 처음 들어온 때부터 30문항이 처음 다 찬 때까지 |
| 문항별 입력 횟수 | 문항마다 답을 넣은 횟수. 단답형은 "다음"이나 "넣기"를 누른 횟수 |
| 입력 확인에서 고친 문항 수 | 입력 확인 화면의 바텀시트에서 값이 바뀐 문항 수 |
| 표시 화면에 머문 시간 | 표시 화면에 들어온 때부터 나간 때까지를 모두 더한 값 |
| 시험 선택부터 첫 점수까지 | 시험 선택 화면에 처음 들어온 때부터 점수 화면에 처음 닿은 때까지 |
| 남은 오입력 | 진행자가 붙여 넣은 답지와 참가자가 최종 제출한 답이 다른 문항 수 |
| 받지 않은 누름 | 연달아 누르기 보호가 받지 않은 누름의 수(1.1). 측정에 묶인 화면에서만 세고, 진행자용 화면과 예시 결과, 측정에 묶이지 않은 기록의 화면에서 버려진 누름은 세지 않아요. 빈 바탕을 누른 것도 버렸으면 세요 |

"답 입력 시간"에는 입력 확인 화면에서 고친 시간이 들어가지 않아요. 고친 시간까지 보려면 화면 진입 기록에서 input 과 marks 사이의 시간을 봐요.

알아 둘 것:

- 참가자를 마친 뒤에는 누가 그 시험 기록을 고치거나 지워도 그 측정의 최종 답과 남은 오입력이 바뀌지 않아요. 시험 기록을 지운 뒤에도 답지를 대조할 수 있어요.
- 화면 진입 기록에서 이름이 other: 로 시작하는 줄은 이번 측정에 묶이지 않은 기록(기기에 남아 있던 다른 기록, 채점을 마친 뒤에 새로 시작한 기록)의 화면이에요. 그 화면의 시각은 답 입력 시간, 표시 화면에 머문 시간, 첫 점수까지의 시간에 쓰지 않아요. 진행자용 화면에 들어온 것은 test 로 적혀요.
- 참가자가 측정 중에 다른 시험 기록으로 옮겨 가면(시험을 다시 고르거나, 자기가 넣던 기록을 기록 화면이나 "이어서 보기"로 다시 열면) 측정도 그 기록으로 옮겨 가요. 앞 기록에서 재던 값은 따로 넣어 두었다가 그 기록으로 돌아오면 이어 써요. 옮겨 간 횟수는 측정 카드와 CSV의 exam_reselects 칸에 적혀요. 0이 아니면 답 입력 시간에 다른 시험에 다녀온 시간이 들어 있을 수 있으니 화면 진입 기록을 함께 봐요.
- 채점까지 마친 뒤에 같은 참가자가 시험을 새로 시작해도 그 기록은 재지 않아요. 측정은 채점한 기록에 묶인 채로 있고, 그 기록을 지워도 측정값과 최종 답은 남아요.

## 6. 측정 기록 내보내기

1. 모든 참가자가 끝나면(또는 하루 일정이 끝나면) `#/test` 화면 아래 "내보내기"로 가요.
2. "JSON 파일 저장"과 "CSV 파일 저장"을 눌러 파일로 받아요. 파일 이름은 score-anatomy-test-날짜-시각 이에요. 폰에서 저장이 안 되면 "JSON 복사", "CSV 복사"로 복사해서 메모 앱에 붙여 넣어요.
3. 파일을 컴퓨터로 옮긴 것을 확인한 뒤 "기록 초기화"를 눌러요. 초기화는 측정 기록만 지워요. 참가자가 넣은 시험 기록은 기록 화면의 "이 기기의 기록 모두 지우기"로 지워요.

- CSV는 한 줄이 한 번의 시도예요(참가자 한 명이 두 줄). 칸: participant, input_mode, planned_exam, exam, exam_reselects, started_at, input_seconds, input_count, review_fixed_count, marks_seconds, select_to_score_seconds, residual_errors, residual_items, discarded_taps, screens, inputs_q1 부터 inputs_q30.
- JSON에는 화면 진입 시각 전부와 최종 제출한 답이 들어 있어요.
- 기록은 어디로도 전송되지 않아요. 참가자 본인 폰으로 했다면 그 폰에서 꺼내고 초기화까지 하고 돌려줘요.
- 참가자 코드와 실제 사람을 잇는 표는 종이로만 가지고 있다가 분석이 끝나면 없애요.

## 7. 통과 기준 (제안값, 방향 확인용)

숫자는 모두 제안값이에요. 통계 검증이 아니라 방향을 보는 용도예요. 기준에 못 미치면 "실패"가 아니라 어디가 막혔는지 관찰 기록과 함께 보고 고칠 곳을 정해요.

| 항목 | 기준 |
| --- | --- |
| 답 입력 | 중앙값 75초 이하, 남은 오입력이 있는 참가자 1명 이하 |
| 첫 점수까지 | 도움 없이 180초 안에 도달한 참가자가 4명 중 3명 이상 |
| 표시 화면 | 참가자별 "표시 화면에 머문 시간"의 중앙값 40초 이하, 감점되는 줄 알았다고 말한 참가자 1명 이하 |
| 읽기 질문 | 3개를 모두 맞힌 참가자가 5명 중 4명 이상 |

- 답 입력 기준은 입력 방식별로 따로 봐요(키패드 방식의 중앙값, 5행 방식의 중앙값).
- "4명 중 3명"(75%), "5명 중 4명"(80%)은 비율이에요. 첫 점수 기준(4명 중 3명)은 8명이면 6명, 9명이면 7명, 10명이면 8명 이상이에요. 읽기 질문 기준(5명 중 4명)은 8명이면 7명, 9명이면 8명, 10명이면 8명 이상이에요.
- 표시 화면 40초는 참가자별 "표시 화면에 머문 시간"의 중앙값으로 봐요(1.1에서 중앙값으로 확정했어요). 모든 참가자가 40초 이하여야 하는 기준이 아니에요.
- 결과를 적을 때는 늘 분모를 함께 적어요(예: "8명 중 6명").

## 8. 함께 적어 둘 관찰

- 답을 넣다가 시험지와 화면을 번갈아 본 횟수가 많았는지, 다섯 문항마다 맞춰 보는지.
- 단답형에서 "다음"을 누르지 않고 멈춘 적이 있는지. 숫자 두 줄 키패드에서 헤맸는지.
- 잘못 넣은 답을 어떻게 고쳤는지(지우기, 칸 누르기, 입력 확인 화면).
- 앞 칸을 고친 뒤 키패드가 잠기는 것(1.1)을 이해하는지. 키패드 방식에서 답이 든 칸을 눌러 고치면 그 칸에 머물고 키패드가 잠겨요. 키패드 위에 "N번에 답을 넣었어요. 다음에 할 일을 골라 주세요."와 "M번도 고치기", "K번부터 이어서 넣기" 버튼이 나와요. 잠긴 동안 누른 답 키는 들어가지 않아요. 참가자가 잠긴 키를 계속 누르는지, 버튼을 찾는지, 안내문을 읽는지 봐요.
- "지우기"가 눈에 보이는 지금 칸부터 지우는 것을 예상하는지. 지금 칸이 비어 있고 답을 넣어 저절로 넘어온 칸이면 앞 번호로 가서 지워요.
- "K번부터 이어서 넣기"를 누른 직후에 "지우기"를 누르면 K-1번이 지워져요. 고친 칸 바로 다음이 K번이면 방금 고친 답이 지워지고, 그 사이에 답이 든 칸이 있으면 방금 넣은 답이 아닌 칸이 지워져요(예: 12번을 넣을 차례에 9번을 고친 뒤 "12번부터 이어서 넣기"를 누르고 지우면 11번). 이때 놀라거나 다시 넣는지 봐요.
- 빈칸을 잘못 눌러 다른 묶음으로 갔을 때 원래 칸으로 어떻게 돌아가는지 봐요(빈칸을 눌러 들어온 칸에는 돌아가는 버튼이 없어요).
- 다 찬 채로 답 입력 화면을 다시 열면 키패드가 모두 잠겨 있고 "빈칸이 없어요. 고칠 문항을 눌러 주세요."가 떠요. 칸을 눌러 고치는지 봐요.
- 잠금 안내(정보, 왼쪽 줄이 회색)와 오류 안내(경고, 왼쪽 줄이 경고색: 밝은 화면에서 갈색, 어두운 화면에서 노란색)를 구분해서 읽는지 봐요.
- 화면이 바뀐 직후에 누른 키가 들어가지 않은 적이 있는지. 화면이 바뀌고 0.5초 안에 바로 앞에 누른 자리를 다시 누르면 받지 않게 해 뒀어요(연달아 누르기 보호). 단답형 숫자 키는 이때도 받아요. 키패드 방식에서 마지막 문항을 넣어 입력 확인으로 넘어간 직후 0.5초는 화면 어디를 눌러도 받지 않아요. 받지 않은 누름이 버튼이나 키 위였으면 "화면이 막 바뀌어서 방금 누른 것은 받지 않았어요."가 2초 동안 떠요(1.1). 이 알림을 보고 다시 누르는지, 알림이 거슬리는지 봐 주세요. 측정 카드의 "받지 않은 누름"과 함께 봐요.
- 단답형 키패드의 배열과 자리(사용성 테스트에서 볼 질문). 지금은 숫자를 두 줄(1~5, 6~0)로 놓았고, 단답형 키패드의 1~5 줄은 5지선다 키패드의 1~5보다 한 줄 위에 있어요(5지선다의 1~5 자리에는 6~0 줄이 와요). 다음을 관찰하고 끝에 물어요.
  - 5지선다에서 단답형으로 넘어가는 문항(예시 시험 A의 22번, B의 16번과 29번)에서 숫자를 잘못 누르거나 멈칫하는지.
  - 두 줄 배열에서 숫자를 찾느라 헤매는지. 전화기 배열(세 칸 네 줄)이 더 익숙하다고 말하는지.
  - 질문: "숫자 키가 놓인 자리가 헷갈린 적이 있었나요? 전화기 숫자판처럼 놓여 있으면 더 편할 것 같나요?"
- "고민"과 "찍음"의 차이를 묻는지, 세 번 눌러 지우는 것을 아는지.
- 점수 해부 화면에서 "약 75점"을 자기 점수로 읽는지, 막대의 무늬를 구분하는지.
- 불편하거나 불안하게 느낀 말이 있었는지.
